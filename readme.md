# Crazy Faces

Este projeto transforma uma pintura minha num artefacto digital interativo. Escolhi o meu desenho para revisitar as caras que criei e observar a pintura de outra forma. Queria perceber como uma imagem estática pode ganhar comportamento no ecrã e aprofundar os meus conhecimentos digitais, experimentando como código, movimento e interação prolongam uma prática artística.

Input: a imagem fornece várias caras e uma composição cromatica bastante interessante. O uso do cursor, de cliques,da barra de espaço e do tempo alimentam esta experiência. 

Expressão: em p5.js, os olhos seguem o cursor e piscam em tempos diferentes e ao clicar perto de uma cara fixa o olhar das restantes nela. A barra de espaço liberta o olhar, que volta ao cursor. Esta dinâmica cria vários tipos de movimentos na sua composição e evita sequências sempre iguais.

Quis substituir o cursor por um pincel laranja, referência ao desenho e ao ato de pintar. Output: uma experiência interativa para browser, que anima sem apagar a pintura original. Move o pincel para explorar os olhares, clica perto de várias caras para mudar o foco, pressiona no espaço para voltar ao seguimento do cursor.

Usei o Copilot como ferramenta de apoio em partes do código. Testei e ajustei o resultado no browser, procurando compreender as interações. O projeto permanece em p5.js.
